- **步骤色彩语义**：问题/过程/解决三段式映射到向导步骤指示器（灰=未达，紫=当前，绿=完成）。

  亮暗双主题 4.5:1 对比、可见焦点环、prefers-reduced-motion。

## 1. 设计原则

1. **对普通用户友好**——默认值永远可用：打开即可跑 mock 流程，模型下载一键完成。
2. **暗黑模式是一等公民**——不是亮色主题的附属品；两套主题对比度均按 WCAG AA 校验。
3. **工作流可视化优先**——一切状态（节点进度/工件/错误）优先用图形表达，文字兜底。
4. **中日韩排版细节**——竖排、全角标点、字体度量在渲染层集中处理，UI 不散落 hack。

## 2. 色彩 Tokens

实现载体：`src/src/index.css`（CSS 变量）+ `data-theme` 属性切换（`src/src/lib/theme.ts`）。

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#fafafa` | `#111114` | 页面背景 |
| `--surface` | `#ffffff` | `#1b1b20` | 卡片/面板 |
| `--surface-2` | `#f0f0f3` | `#26262c` | 次级面板/输入框 |
| `--border` | `#e2e2e8` | `#33333b` | 边框/分隔线 |
| `--text` | `#1a1a1f` | `#e8e8ec` | 正文 |
| `--text-dim` | `#6b6b76` | `#9b9ba6` | 次要文字 |
| `--accent` | `#7c5cff` | `#9d85ff` | 主操作/选中态（品牌紫） |
| `--ok` | `#1a9e5c` | `#3ecf8e` | 成功/完成节点 |
| `--warn` | `#d97706` | `#f5a623` | 运行中/警告 |
| `--err` | `#dc2626` | `#f87171` | 失败/破坏性操作 |

**约定**：涨跌/成败语义遵循中国惯例（红=错误与危险），进度绿=完成。暗色下所有前景色对比度 ≥ 4.5:1。

## 3. 字体与排版

- UI 字体栈：`system-ui, "Segoe UI", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`
- 漫画渲染字体：用户自选（设置页），渲染 crate 只做度量，不绑定字体。
- 字号阶梯：`12 / 13 / 14 / 16 / 18 / 24 / 32`（px），行高 1.5（正文）/ 1.2（标题）。

## 4. 组件

- **侧边导航**（`Layout.tsx`）：图标+文字，当前项 accent 高亮。
- **节点卡片**（工作流画布，React Flow）：状态色环（排队灰/运行 warn 脉冲/完成 ok/失败 err）、

- **进度**：模型下载为线性进度条+速度；页级管线为节点状态矩阵。
- **对比滑块**：修复前后图对比（编辑器）。
